# SmartVision - Deepfake Detection

SmartVision is a prototype deepfake image detection system that classifies images as real or AI-generated using transformer-based models.

## Features
- Upload image for analysis
- Real vs Fake classification
- Confidence score output
- Clean web interface (Flask)

## Tech Stack
- Python
- Flask
- Vision Transformer (ViT)
- Hugging Face Transformers

## Note
This project is a prototype implementation using pretrained models. Due to hardware constraints, full-scale training on large deepfake datasets is proposed as future work.

## Future Improvements
- Fine-tune model on deepfake datasets
- Improve accuracy and robustness
- Add attention heatmaps
- Deploy optimized lightweight model
